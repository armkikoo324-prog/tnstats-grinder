# tnstats-grinder

> **armkikoo324-prog/tnstats-grinder**: The powerful script that automatically grinds when you're not at home and leave while you're at work or school.

---

## 🚀 Features

- ⚡ **Auto-Grind Engine**: Runs continuous grinding tasks automatically in the background.
- 📱 **Mobile & Desktop Friendly**: Managed and hosted directly via GitHub.
- 🛡️ **Anti-Idle / Automation**: Designed to keep your progress going while you are at school, work, or AFK.

---

## 📥 Installation

1. Install a user script manager in your browser:
   - **Chrome / Edge / Firefox**: [Tampermonkey](https://www.tampermonkey.net/)
   - **Safari / iOS**: [Userscripts](https://github.com/quoid/userscripts) or Tampermonkey
2. Open the direct raw link to the script:
   - Click on [`grind-automation.user.js`](./grind-automation.user.js) in this repo.
   - Click the **Raw** button at the top right of the file view.
3. Tampermonkey will prompt you to install the script automatically—click **Install**.

---
